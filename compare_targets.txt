# compare_targets.txt — collectors to mirror so the HOSTED phone can Compare
# them with no PC.
#
# One collector per line: a NAME (exactly as it shows on lpubelts, e.g. Sidepicks)
# or their PROFILE LINK (https://lpubelts.com/#/profile/<id>). A name is looked up
# on LPU's public leaderboard, just like the app's Compare box; if a name isn't
# found, paste that person's profile link instead.
#
# Lines starting with # are ignored, and so are blank lines. UPDATE-THUMBS.bat
# reads this file every run, so add someone once and they stay refreshed.
# Delete a line to stop mirroring that collector (their old file is left in place;
# remove collections/<id>.json by hand if you want it gone).
#
